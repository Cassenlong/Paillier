# Paillier

本仓库使用 Python 实现了 Paillier 公钥加密算法，并通过示例程序验证 Paillier 加密算法的加法同态性质。同时，仓库还基于 Paillier 算法实现了一个简单的匿名电子投票模拟系统。

## 项目简介

Paillier 是一种具有加法同态性质的公钥密码算法。它允许在不解密密文的情况下，对密文进行特定运算，使得解密后的结果等价于明文上的加法运算。

本项目主要包含两个部分：

1. Paillier 加密算法的基础实现
2. 基于 Paillier 同态性质的电子投票模拟

通过本项目，可以直观理解 Paillier 算法的基本流程以及其在隐私保护计票场景中的应用。

## 主要功能

* 生成 Paillier 公私钥参数
* 对整数明文进行加密
* 对密文进行解密
* 验证 Paillier 算法的加法同态性质
* 模拟匿名电子投票流程
* 对每位投票者的投票结果进行加密
* 在密文状态下完成票数统计
* 解密并公布最终投票结果

## 文件说明

### `Paillier.py`

该文件实现了 Paillier 加密算法的核心功能。

主要内容包括：

* 随机生成大素数 `p` 和 `q`
* 计算公钥参数 `n` 和 `n²`
* 计算私钥参数 `λ`
* 随机选择生成元 `g`
* 实现加密函数 `Encrypt`
* 实现解密函数 `Decrypt`
* 通过密文相乘验证 Paillier 的加法同态性质

在程序运行时，用户可以输入两个整数明文，程序会分别进行加密和解密，并计算两个密文相乘后的解密结果。

Paillier 的加法同态性质可以表示为：

```text
D(E(m1) · E(m2) mod n²) = m1 + m2 mod n
```

也就是说，在密文层面进行乘法运算，解密后对应的是明文层面的加法运算。

### `ElectronicVoting.py`

该文件实现了一个基于 Paillier 算法的匿名电子投票模拟系统。

系统流程如下：

1. 设置候选人数和投票人数。
2. 每位投票者为候选人投票。
3. 每位投票者只能选择一名候选人。
4. 每张选票被表示为由 `0` 和 `1` 组成的向量。
5. 系统对每个候选人的投票结果分别加密。
6. 计票人在不解密单张选票的情况下，对密文进行乘法统计。
7. 公布人对最终密文统计结果进行解密。
8. 输出每位候选人的最终票数。

例如，如果有 3 名候选人，某位投票者选择第 2 名候选人，则该投票者的选票可以表示为：

```text
[0, 1, 0]
```

系统会分别对 `0`、`1`、`0` 进行加密，并在密文状态下完成所有投票者的票数累加。

## Paillier 算法流程

本项目中的 Paillier 算法主要包括以下步骤：

### 1. 密钥生成

随机生成两个大素数：

```text
p, q
```

计算：

```text
n = p × q
n² = n × n
λ = lcm(p - 1, q - 1)
```

然后随机选择满足条件的生成元 `g`。

### 2. 加密

给定明文 `m` 和随机数 `r`，密文计算方式为：

```text
c = g^m · r^n mod n²
```

### 3. 解密

对密文 `c` 进行解密，恢复原始明文 `m`。

### 4. 同态性质验证

对于两个明文 `m1` 和 `m2`：

```text
E(m1) · E(m2) mod n²
```

解密后可以得到：

```text
m1 + m2
```

这说明 Paillier 支持加法同态。

## 电子投票原理

电子投票系统利用 Paillier 的加法同态性质实现密文计票。

对于每位候选人，系统将所有投票者对应候选人的加密票数相乘：

```text
E(v1) · E(v2) · ... · E(vk) mod n²
```

解密后得到：

```text
v1 + v2 + ... + vk
```

也就是该候选人的总票数。

因此，计票过程中不需要解密每一张单独选票，只需要解密最终统计结果。
